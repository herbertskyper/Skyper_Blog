# 前言

好久没有动笔写作文了，上一次写还是在高考。虽然赛博动笔也不是真的动笔，杂谈也不是真的作文，但是还是值得纪念一下这第一篇非功利目的写的杂谈，在正式开始之前，先说一点题外话。其实本人曾经非常讨厌语文，对写作文提不起兴趣，但是渐渐发现，我讨厌的只是应试语文罢了。最近看一些辩论赛，也想试着表达一下自己的观点，遂作此篇。曾经的我写的作文里塞满了各处“模仿”来的生晦名词，大部分词都没有真正理解他的含义，可是这确实让我的作文分数提升了许多，确实有些幽默。但是，对于那些我感觉自己懂了的词，现在也发觉未能真正理解其内涵，题目中的两个词就是其中的显著代表。本文应该不能像曾经的我那样在文中四处引经据典而显得高大尚，我只能用我粗浅的语言表达我的理解，望谅解。

# 内卷

## 内卷究竟是什么？

这个问题很难有一个标准答案。犹记得第一次接触这个词是高中语文组发的阅读材料，那篇文章是一篇大学教授关于内卷与躺平的文章，不用说就知道是那种呼吁大家别躺平，用于内卷，不内卷是不够勇敢之类的说辞。那个时候的我只是以为内卷就是努力，不内卷就是躺平不努力。现在发现我大错特错，内卷较为正式的定义是一种在有限资源下，个体或群体为了争夺微小的优势而不断加码努力，却收获甚微的现象。当大把的努力被浪费，当梦想的彼岸离我们越来越远时，为何我们还能沉得住气而不是对残酷的社会发出一声质问。内卷是我们花大量时间学某些这辈子都用不到的知识，受某些看不见的大手牵制而做了大量的无用功却仍面临gctt的风险，无法得到心之所向时的无所适从。我们没法逃离这个时代，所以也无法远离内卷，内卷处在这个世界的各个角落。看过一位B站up主漫士的关于内卷的视频，其中提到内卷是人按照同样的利益最大化的方法向同一个目标进发，所以内卷也扼杀了人们的创造力。这说的非常对，达成高绩点近乎只有一条方法，那就是不停刷题，不停背书等机械式的方法，充满了乏味，同时还扼杀了学生的想象力与创造力。


## 反内卷意味着躺平吗？

> 人生最大的和解，是接受自己是一个普通人。我们要有勇气去面对一个残酷的现实，远方除了远，可能什么都没有。我们用尽了所有的努力，可能终其一生却只能做一个平凡人。

放弃内卷其实很难，因为有着优绩主义的诱惑，如果想要获取某些利益，如果参与内卷，我们能做的只有做好失败的准备，放过自己，接受自己的平庸，然后随其自然。放弃内卷并不完全意味着躺平，我们只是换了一条努力收益更大的道路罢了。反内卷只是意味着不要一味盲目内卷，而要多看看别处。

# 优绩主义

我一直以为优绩主义是不合理的，直到我看完了一场新国辩关于优绩主义的辩论，我意识到优绩主义有其一定的合理性。其实从反面思考我们就可以发现这点，因为我们会发现很难找一个更好的制度来取代它。许多人鼓吹西方快乐教育，却没有看到西方底层人民根本没法得到合理教育的现状以及学生身上背负的巨额学费债。

当然优绩主义和内卷有很强的关联性，好的成绩会获得更好的奖励，这会导致很多人为了奖励不顾一切参与内卷，从而丧失了身上的一些“自由”。


# 时代与我们

## 人生应如旷野？

新国辩有一道辩题，人生应如旷野还是应如轨道。很多人的第一想法都是旷野，认为没有人想失去自由。想回答这个问题，就不得不提到“自由的消解”。当我们上大学的时候，有多少人没有陷入过迷茫，纠结自己究竟想干什么，自己终将何去何从？这个时候，我们难道不是更希望天下掉下来一条轨道，告诉我们究竟应该驶向何方？我们不想要那种毫无指引的旷野，我们不想在旷野上四处打转却找不到一条明确的道路。当今时代，确实有那么一条看起来最正确的铁轨，那就是优绩主义的铁轨。于是，越来越多的人涌向这条路，参与内卷，因为他们不想自己做选择，不想当自己选择错误时责怪自己。所以，当他们发现自己失败时，会陷入更深的迷茫，因为他们或许从来没想过自己真真想要的是什么。

## 我们何去何从？

看看我自己吧，我也深陷内卷的漩涡之中，时常会为自己要做的无用的努力而感到愤慨。但是，我明白自己想要什么，慢慢接受现状。我们只需要明白的是，不能为了内卷而内卷，想好自己想要什么，为自己的选择负责，不盲目从众，似可逃脱出时代的洪流。但是，没有适用所有人的方法论，自己终将去向何方，只有自己明白。在时代的长河中，我们如同漂泊的孤舟，被“浪潮裹挟前行。但在时代的画卷上，我们每个人都是一笔独特的色彩。
